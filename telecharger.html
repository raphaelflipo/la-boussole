Installation

Ouvrir l’application
la première fois.

La bêta n’est pas encore signée par Apple ni par Microsoft. Votre système affiche donc un avertissement au premier lancement : c’est normal, voici comment continuer.

Mac

  1. Ouvrez l’archive ZIP, puis glissez La Boussole dans le dossier Applications.
  2. Double-cliquez sur l’application. macOS indique qu’il ne peut pas vérifier le développeur.
  3. Ouvrez Réglages Système › Confidentialité et sécurité, puis cliquez sur « Ouvrir quand même ».

Windows

  1. Extrayez entièrement l’archive ZIP (clic droit › Extraire tout).
  2. Lancez LaBoussole.exe. Si l’écran « Windows a protégé votre ordinateur » apparaît…
  3. …cliquez sur « Informations complémentaires », puis « Exécuter quand même ».

Android

  1. Téléchargez le fichier APK depuis votre téléphone.
  2. Ouvrez-le. Android demande l’autorisation d’installer des applications depuis cette source.
  3. Autorisez-la pour votre navigateur, puis touchez « Installer ».

Chaque fichier sera accompagné de son empreinte SHA-256, pour vérifier qu’il n’a pas été modifié.

Transparence

Ce que contient
l’application.

La Boussole est développée par Raphaël Flipo dans la métropole lilloise. Elle s’appuie sur des composants open source reconnus.

  • Interface Qt 6 (licence LGPL v3) : les textes de licence et le code source des composants Qt utilisés sont fournis avec chaque version.
  • Chiffrement OpenSSL 3 (licence Apache 2.0) pour les connexions HTTPS.
  • Cartes OpenStreetMap, avec attribution, sans position GPS demandée automatiquement.
  • Aucune publicité ni traceur dans l’application.
  • Vos données restent dans l’espace privé de votre association.
