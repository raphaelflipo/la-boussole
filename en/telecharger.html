Platform availability

⌘

macOS

The universal 1.0 disk image, build 10006, was rebuilt from the common source for macOS 14.4 and later. Startup was checked on Apple Silicon, including under Rosetta. The household booking test in the Mac screenshots used the earlier build 10005. The package uses a local ad hoc signature and has no Apple notarisation. Testing on an Intel Mac remains pending.

Android

The private 1.0 ARM64 APK declares Android 9 as its minimum. Build 10006 was tested in an API 36 emulator by cancelling part of an iOS booking and confirming the updated state on iOS. The existing development signature was kept. Swipe gestures and testing on physical phones remain pending.

iPhone and iPad

Build 10006 was tested on an iPhone 18 Pro simulator running iOS 27.2. The test covered a household round trip, cancellation from Android, cross-platform synchronisation and a swipe gesture. It also launched on a personal iPhone 17 running iOS 27.3. The complete flow on that phone still needs testing. The temporary personal signature must be renewed in Xcode. Public App Store, TestFlight and general iPhone or iPad downloads are unavailable.

Install a private build

  • Mac. Open the disk image and copy La Boussole.app into Applications. The local signature is subject to macOS security checks.
  • Android. Open the supplied ARM64 APK and follow your phone’s installation permissions. The package includes the dependencies you need.
  • Personal iPhone. Install from Xcode with your own account and an authorised device. Renew the free provisioning profile when it expires.
  • Use an invited test account and an internet connection. The free test server may need time to start after inactivity.
