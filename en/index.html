From the event
to the ride home.

I started La Boussole to make my scout troop’s trips easier to organise. The same process can help other volunteer-led groups.

Manage the group

Invite members, review membership requests and assign responsibilities within an association.

Share event details

Give participants the meeting point and practical details for the next activity.

Fill the available seats

Offer a ride and keep track of seat bookings. In the private 1.0 demo, households can book for several passengers and cancel only the seat or leg that has changed.

Platform availability

The native applications are in private demonstration. Public installers and subscriptions are currently unavailable.

macOS

Private 1.0 DMG. The household booking flow has been tested.

Windows

The 1.0 build is pending because of the build service’s free quota.

iOS

The household flow was tested in the simulator. Public installation is unavailable.

Android

Private APK. Partial cancellation was tested in the emulator.

FAQ

Can my group use it today?

You can explore the fictional browser demo. A pilot using real group data is still being prepared.

Can I add a ride for the return leg only?

The private 1.0 flow handles outbound and return legs separately. The browser demo covers a simpler scenario.

Does the demo send my information?

The demo handles its fictional scenarios in your browser. Read the privacy notice.
