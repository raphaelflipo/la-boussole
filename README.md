# La Boussole — site

Site de présentation et de téléchargement de La Boussole : https://raphaelflipo.github.io/la-boussole/

Site statique, sans cookie ni traceur. Le code de l’application n’est pas dans ce dépôt.

Pour ouvrir les téléchargements : publier une version (Releases) avec les fichiers Mac, Windows et Android, renseigner les empreintes SHA-256 dans `downloads.js`, puis passer `enabled` à `true`.
